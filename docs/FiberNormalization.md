# Normalization and monomial-map kernels

Import `ToricIdeals.MonoidAlgebra.FiberNormalization`, or the root `ToricIdeals`.
The four results are in `ToricIdeals.AddMonoidAlgebra`. All coefficient and index
universes are independent.

## Coefficientwise criterion

Let `R` be any ring, `M` an additive monoid, `N` any type, `I` a left ideal of
`AddMonoidAlgebra R M`, and let `exponentMap : M → N` and `normal : N → M` be
functions. Suppose that, for every `m : M` and every `r : R`,

```lean
AddMonoidAlgebra.single m r -
  AddMonoidAlgebra.single (normal (exponentMap m)) r ∈ I
```

Then `mem_ideal_of_mapDomain_eq_zero` shows that
`AddMonoidAlgebra.mapDomain exponentMap f = 0` implies `f ∈ I`.
This map sums coefficients over the fibers of the index function. With a bare
target type it has no asserted multiplication, and even when the target carries
an additive monoid structure an arbitrary index function need not induce a ring
map. Neither the coefficient ring nor the source monoid must be commutative.
The function `normal` need not select a preimage, preserve addition or be a section.

The argument subtracts the normalized coefficient sum from `f`. That difference
is a finite sum of the assumed ideal members. Functoriality of coefficient
summation makes the normalized sum zero whenever the original map is zero.

## Ring-map criteria

Now also assume `[AddMonoid N]` and take `exponentMap : M →+ N`.
Mathlib supplies `AddMonoidAlgebra.mapDomainRingHom R exponentMap`.
The same all-coefficient basis congruences give:

- `ker_mapDomainRingHom_le`: its kernel is contained in `I`.
- `ideal_eq_ker_mapDomainRingHom`: `I` equals that kernel, provided separately
  that `I ≤ RingHom.ker (AddMonoidAlgebra.mapDomainRingHom R exponentMap)`.
- `mem_ideal_iff_mapDomain_eq_zero`: under that same separate inclusion,
  membership in `I` is equivalent to the coefficient map vanishing.

The reverse inclusion is essential: the top ideal always satisfies any basis
congruences, but it is not the kernel of an identity map over a nonzero ring.
No two-sidedness premise is needed; equality with a ring-homomorphism kernel
implies two-sidedness. No domain, generic nontriviality, exponent-surjectivity
or global-section premise is imposed.

## Examples and use

`ToricIdealsTest.FiberNormalizationExamples` supplies independent coefficient
and ideal calculations. The ideal generated by `single 1 1 - single 0 1` in
`AddMonoidAlgebra R ℕ` satisfies every coefficient congruence for the constant-zero
exponent homomorphism and lies in its kernel. Over `ℤ` this ideal is nonzero and
proper. `ToricIdealsTest.FiberNormalizationClient` uses the criterion to identify
that kernel and characterize ideal membership, for every ring `R`.

The examples also cover nonsurjective doubling with normalization by halving,
zero coefficient rings, noncommutative matrix coefficients, noncommutative free
additive exponents, and arbitrary index functions such as nonadditive division
by two. Exponent surjectivity and surjectivity of the induced ring map are not
identified: over a zero ring the latter can hold without the former.

Ordinary commutative/bundled-map applications of the coefficientwise criterion
use the homomorphism's function coercion. An explicit `@` application should
supply the ring and source additive-monoid instances only; the target additive
instance is needed for the three bundled ring-map criteria, not for the raw
coefficientwise criterion.
